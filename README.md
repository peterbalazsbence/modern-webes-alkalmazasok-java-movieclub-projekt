# MovieClub

Filmes közösségi alkalmazás a Modern webes alkalmazások (Java) tárgyhoz.

**Kezdés:** [OLVASS-EL.md](OLVASS-EL.md)

Windows alatt: **INDITAS.cmd**, majd http://localhost:8080.

## Funkciók

Filmkatalógus és keresés, 1–5 csillagos értékelés, saját nézési lista, személyes ajánlások, tag/moderátor szerepkörök, TMDB-import.

## Projekt

- Java 21, Spring Boot 3.5.16, Maven multi-module.
- Spring MVC, Security, Data JPA, Liquibase, H2.
- 27 JUnit 5 / Mockito / Spring-integrációs / HTTP-komponens teszt.
- Magyar, reszponzív felület, helyi grafikai elemekkel.
